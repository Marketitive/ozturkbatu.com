## 🚀 Deploy Now (3 Simple Steps)

### Step 1: Push to GitHub (2 minutes)

```bash
cd /Users/batuhanozturk/ozturkbatu/Website/ozturkbatu-web

git add .
git commit -m "Ready for production deployment"
git push origin main
```

### Step 2: Deploy on Netlify (5 minutes)

1. **Go to**: https://app.netlify.com/start
2. **Click**: "Import from Git"
3. **Select**: GitHub (authorize if needed)
4. **Choose**: Your repository
5. **Build settings**:
   - Build command: `npm run build`
   - Publish directory: `dist`
   - Node version: 18 or higher
6. **Click**: "Deploy site"
7. **Wait**: 2-3 minutes for first deploy

### Step 3: Add Custom Domain (10 minutes)

1. **In Netlify Dashboard**:
   - Go to: Site settings → Domain management
   - Click: "Add custom domain"
   - Enter: `www.ozturkbatu.com`
   - Click: "Verify"

2. **Update DNS** (at your domain registrar):
   - Netlify will show you DNS records
   - Add the provided records
   - Wait 24-48 hours for propagation

3. **SSL Certificate**:
   - Netlify automatically provisions this
   - Enabled once DNS is configured
   - Your site will be HTTPS ✓
